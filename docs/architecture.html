Factory Inventory Management System — Architecture Overview

A full-stack inventory & order management demo: Vue 3 frontend, FastAPI backend, in-memory mock data (no database).

Tech Stack

Frontend

Vue 3 + Vite

  • Composition API throughout
  • Vue Router (client-side, history mode)
  • Axios for HTTP
  • Custom SVG charts, CSS Grid layouts
localhost:3000
Backend

Python + FastAPI

  • Pydantic models for request/response validation
  • Shared filter helpers (warehouse, category, status, month)
  • CORS open (dev only)
  • Auto-generated Swagger docs
localhost:8001
Data

JSON + In-Memory

  • No database — flat JSON files
  • Loaded once at server startup
  • Filtering done in Python, in memory
  • Restart server to reload data
